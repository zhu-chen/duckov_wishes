# 逃离鸭科夫祈愿 Mod /Duckov Wishes Mod

传说，只要你的愿望足够强烈，鸭鸭之神便会投下目光......

本 Mod 为游戏《逃离鸭科夫》设计，允许玩家通过一个简单的游戏内界面“祈愿”想要的物品，从而大幅提升它们在战局中的出现概率。这下再也不用担心捡不到某件物品了！（酸奶：？）

## ✨ 功能特性

- **物品祈愿**: 可以指定一个或多个物品的ID，动态提升它们的生成概率。
- **权重倍率**: 提供一个可调节的倍率（1-50），用于进一步增加祈愿物品在随机掉落池中的权重。
- **游戏内UI**:
    - 按 `F8` 键可随时打开或关闭配置界面。
    - 界面包含物品ID输入框、倍率输入框、“应用”按钮和“重置”按钮。
- **动态应用**: 无需重启游戏，设置即可实时生效。
- **重置功能**: 一键恢复游戏的默认掉落率。

## 🚀 如何使用

1. **打开/关闭菜单**:
   - 进入游戏后，按下 `F8` 键即可打开配置面板。再次按下可关闭。

2. **配置祈愿**:
   - **物品ID**: 在“祈愿物品ID”输入框中，输入你希望提升掉率的物品ID。多个ID之间请使用逗号（`,`）分隔。
     > 例如: `101,202,303`
   - **倍率**: 在“倍率”输入框中，输入一个 `1` 到 `50` 之间的整数。这个数字越大，祈愿物品的出现概率就越高。

3. **应用设置**:
   - 点击“**应用**”按钮，你的设置将立即生效。状态栏会提示应用成功。

4. **重置设置**:
   - 点击“**重置**”按钮，将清除所有已应用的祈愿效果，并将物品掉率恢复至游戏默认状态。

## 📦 安装方法

1. 从源码构建：参考官方的MOD文档中的说明自行编译。
2. 下载releases页面中的`duckov_wishes.zip`，解压后将其放入游戏的`Mods`文件夹中（如无则创建）。
3. 从steam创意工坊订阅本Mod，Steam会自动帮你安装。创意工坊地址:[steamcommunity.com/sharedfiles/filedetails/?id=3596231209](steamcommunity.com/sharedfiles/filedetails/?id=3596231209)

## 🔧 从源码构建

如果你希望自行修改或编译本项目，请遵循以下步骤：

1. **克隆仓库**:
   ```bash
   git clone https://github.com/zhu-chen/duckov_wishes.git
   ```
2. **配置项目**:
   - 使用 Visual Studio 打开本项目。
   - 确保项目引用的游戏核心DLL文件路径正确。
   - 你可能需要手动修改 `.csproj` 文件中的 `<Reference>` 路径，使其指向你本地的游戏目录。

3. **构建**:
   - 在 Visual Studio 中，选择 `生成` > `生成解决方案`。
   - 或者使用 `dotnet CLI` 运行以下命令：
     ```bash
     dotnet build
     ```
4. **获取成品**:
   - 编译生成的 `.dll` 文件将位于项目的 `bin/Debug` 目录下。将其按照官方文档中的说明包装好进行安装即可。
